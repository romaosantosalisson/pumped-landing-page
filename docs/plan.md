# Projeto de Landing Page para App fitness

Página com fundo branco e fonte Roboto como principal.
Objetivo é ter uma landing page clean, branca e sofisticada.

## HEAD
- coloque um favicon com um alter(aparelho de fazer exercícios) de cor preta de fundo branco

## Seção HEADER:

Logo no canto esquerdo
- A logo é um PUMPED em um retângulo com bordas arredondadas (feito com CSS)
- o fundo do círculo é PRETO e o nome PUMPED deve ser branco

Botão de download no canto direito
- fundo preto, cor branca
- borda arredondada

## NAVBAR
- Dentro do header crie uma navbar com os itens Home, Portfolio e Contato, use flex-box para alinha-los um ao lado do outro com gap necessário para harmonizar a página. Deve ficar entre a logo e o botão baixar App

## Seção HERO:

A hero deve ter altura 90vh, divido em 3 áreas horizontais:

Esquerda:
Apenas a headline, sem ser grande demais, sem destaque (o destaque é o print do app no meio).
"O app perfeito para acompanhar sua vida fitness."

Centro:
Em destaque a imagem assets/images/image-1.png que é um print do app.

Direita:
Uma lista de pontos-chave sobre o app:
- 🏃🏽 Saúde
- 💪🏻 Exercício
- 👥 Amigos

## Seção de FUNCIONALIDADES:

Vão ser usadas as imagens assets/images/images-2.png e assets/images/image-3.png que serão exibidas da seguinte forma:
- print / texto
- texto / print

Ou seja, irá alternar entre o print na esquerda e um texto explicativo na direita, vice-versa.

Descrição breve de cada print para você gerar um texto adequado:
- imagem-2.png = Contagem de calorias
- print_3.png = Exercícios específicos (corrida, musculação, etc)
- Botão fundo preto e cor branca de texto = 📲 Compartilhamento com amigos

## Seção de CTA (call-to-action):
Botão com fundo transparente na cor preta de download com um texto abaixo dele destacando:
"Totalmente gratuito" com hover que fica com fundo preto e cor branca da letra com borda arredondada.


## Seção de Rodapé:
Apenas com o texto "Todos os direitos reservados ;&copy 2026"
